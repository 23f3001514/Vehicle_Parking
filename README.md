# VEHICLE PARKING APP

A Flask-based web application to manage a vehicle parking system with user and admin roles.

---

# Technologies Used

- Python 3.11.3
- Flask
- Flask-SQLAlchemy
- Bootstrap 5 (for styling)
- SQLite (database)

---

# Roles
- **Admin**:
  - Login only (no registration)
  - Create/Edit/Delete Parking Lots
  - View all parking spots
  - View user details


- **User**:
  - Register/Login
  - View available lots and spots
  - Book and cancel parking spots
